# Appeal Patterns

Load this reference when a character's gap, embodied appeal, costume behavior, or multi-heroine differentiation needs higher resolution.

## Gap Direction Library

A gap needs a credible bridge and a reveal condition. These 24 directions are prompts, not complete personalities:

1. **cold -> warm**
2. **warm -> lethal**
3. **cheerful -> ruthless**
4. **frightening -> gentle**
5. **competent -> helpless**
6. **clumsy -> hypercompetent**
7. **commanding -> approval-starved**
8. **sheltered -> decisive**
9. **pious -> starving**
10. **flirtatious -> shy-when-sincere**
11. **innocent -> calculating**
12. **cynical -> devotional**
13. **noble -> domestic-disaster**
14. **servant -> quiet-authority**
15. **idol -> privacy-hungry**
16. **delinquent -> caretaker**
17. **loud -> silent-under-hurt**
18. **stoic -> petty**
19. **aloof -> conditionally-clingy**
20. **polite -> territorial**
21. **monstrous -> tender**
22. **small -> dominating**
23. **invincible -> sensory-fragile**
24. **healer -> self-destructive**

For each chosen direction, specify:

- public surface
- private or pressure-side counter-trait
- bridge that makes both true
- reveal condition
- who may see it
- what changes after it is seen

## Embodied Appeal as Scene Information

Convert physical appeal through:

`fixed fact -> visual/motion signal -> observer response -> character self-consciousness -> scene consequence`

The fixed fact belongs in the data layer. The rest makes it perform. An observer response is viewpoint-specific, not an objective command that everyone must desire the character.

Reject descriptions that stop at an inventory of body parts. Camera attention must preserve personhood, intention, and scene stakes.

## Clothing as Behavior

Treat clothing as a device that changes:

- posture and range of motion
- professional credibility or role access
- defense, concealment, exposure, and vulnerability
- how a character offers, refuses, repairs, lends, or removes distance
- which relationship may touch, adjust, recognize, or misunderstand it

An outfit tag list is reference data. A character design explains what the outfit makes possible, expensive, or socially legible.

## Multi-Heroine Appeal Portfolio

For each recurring heroine or romance route, record:

| Field                                    | Distinction                                                                          |
| ---------------------------------------- | ------------------------------------------------------------------------------------ |
| **Group role**                           | What the ensemble loses if this person is removed.                                   |
| **Core appeal response**                 | The ranked feeling the audience should seek from them.                               |
| **Access fantasy**                       | What kind of closeness only this character offers.                                   |
| **Priced obstacle**                      | What must be risked, learned, or given up to reach it.                               |
| **Public/private gap**                   | What changes by audience and reveal condition.                                       |
| **Exclusivity stance**                   | Mutual, asymmetric, plural, open, unresolved, or explicitly excluded configuration.  |
| **Jealousy trigger and scarce resource** | What attention, status, ritual, time, or truth cannot be shared without consequence. |
| **Route-only payoff**                    | A reward unavailable in common scenes or another route.                              |
| **Non-overlap axis**                     | The appeal dimension no other cast member may duplicate.                             |

Overlap in surface type is allowed when the access fantasy, obstacle, gap, or payoff differs. Recoloring the same relationship arc is not differentiation.

## Validation

- Can the gap remain hidden under ordinary pressure?
- Does body or clothing attention alter behavior rather than pause the scene?
- Does the camera preserve agency and interiority?
- Can a non-fanservice scene still recognize the character?
- In an ensemble, can each route be identified from access fantasy and obstacle without names?
