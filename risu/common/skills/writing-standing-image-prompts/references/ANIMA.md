# Optional Anima Prompt Recipe

This is a reusable recipe for users who choose Anima or an Anima-to-Illustrious workflow, not a verified model requirement or performance guarantee. Adapt framing, pose, clothing, background, lighting, prompt structure, and output format to the request.

The hybrid recipe combines comma-separated visual tags with an English description of the figure. The natural-language portion can express relationships that tags cannot; it is optional. If shared quality or negative prompts already live in the user's generation settings, the character prompt can omit them.

For a user-selected Anima-to-Illustrious workflow, reuse the established design in each checkpoint's supported grammar. A tag-only Illustrious prompt is one option. Preserve relevant lighting and background decisions unless the workflow or user calls for a change; a second pass does not inherently require a grey background or different crop.
