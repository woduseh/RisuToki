# Trope Library

## Outcome

Select a recognizable pattern, its expected audience promise, and a deliberate play-straight or subversion stance without letting the catalog write the design.

## Workflow

1. Identify the pattern actually carrying the request: character, relationship, species/role, genre, or media convention.
2. Load only the matching reference: `CHARACTER_TROPES.md`, `RELATIONSHIP_TROPES.md`, `SPECIES_ROLE_TROPES.md`, `MEDIA_CONVENTIONS.md`, or the broader `TROPES.md` index.
3. Record expected beats, quality bar, common degradation, and one chosen stance:
   - **Play straight:** deliver the expected beats with specific, high-resolution execution.
   - **Subvert:** preserve legibility while changing one mechanism or consequence.
4. Return the choice to the primary Skill and express it through behavior, conflict, voice, imagery, or structure.

Do not combine catalog entries indiscriminately, force novelty when the user wants a classic execution, or treat trope labels as model-visible characterization.

## Validation

The result should remain recognizable without naming the trope, fulfill the intended audience promise, and contain no unrelated deviations added only to appear original.
