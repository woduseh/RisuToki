# Self-Introduction Character Sheet

Use only when the requested form is the project's self-introduction sheet. This is a particular format, not the default for all characters.

| Part                | Format                                                                                                                           |
| ------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| Profile             | Factual identity, observable appearance, current attire, background, abilities, and other fixed data needed for the character.   |
| Self-introduction   | The character's own account. Voice, emphasis, evasions, and omissions carry characterization instead of an omniscient diagnosis. |
| Closing instruction | Permission to infer and improvise consistently beyond the introduction.                                                          |

The canonical setup is a character speaking alone to a camera. Use a different audience or situation when requested; a diary, public profile, interrogation, or conversation changes what the speaker will volunteer or conceal.

The Compact form covers clothing/style, likes, dislikes, current wants, and present circumstances. The Deep form also covers perceived strengths, difficulties, motives, expectations of others, and intimacy as a topic. These are available forms, not a requirement to fill every topic regardless of the character.

Keep background facts distinguishable from the speaker's self-presentation. The speaker may lie, exaggerate, or omit. Avoid explanatory personality labels and parenthetical action beats in the monologue unless they are deliberately part of the requested form. A plainspoken character may name feelings directly; the format does not require concealment or hidden trauma.

The canonical closing line is:

> This interview is the seed. Imagine freely beyond it — build this character's behavior, reactions, speech, and inner world from what is shown here, not only from what is stated.

Adapt that instruction to the chosen premise. If a fact must remain secret until a condition is met, put it behind that condition rather than expecting the closing line to enforce secrecy. Do not automatically create lorebooks or an opening while producing this sheet.
