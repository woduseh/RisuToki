# Media Profiles

Use only the profiles requested by the project. Every profile defines the medium's native carrier, recurring unit, adaptation pressure, and common failure.

## RisuAI Roleplay

- **Native carrier:** responsive character behavior and user agency.
- **Recurring unit:** turn, scene, relationship-state change.
- **Preserve:** pressure responses, voice, invitation/obstacle, world reaction.
- **Compress:** fixed plot beats that require the user to obey.
- **Expand:** conditional reactions, alternate openings, state residue.
- **Compensate:** replace cinematic montage with recurring sensory cues and event entries.
- **Failure:** scripting the user's feelings or rushing toward a known ending.

## Prose / Light Novel

- **Native carrier:** interiority, narration lens, controlled information.
- **Recurring unit:** scene and chapter.
- **Preserve:** contradiction, metaphor sources, knowledge horizon.
- **Compress:** exhaustive visual description.
- **Expand:** interior misreading, unreliable interpretation, thematic motifs.
- **Compensate:** replace performed micro-expression with selective interior access.
- **Failure:** explaining every gap the visual version let readers infer.

## Manga / Webtoon

- **Native carrier:** page or scroll rhythm, iconic silhouettes, visual juxtaposition.
- **Recurring unit:** panel, page/scroll beat, chapter hook.
- **Preserve:** readable expressions, props, costume anchors, relationship distance.
- **Compress:** lore that cannot be staged visually.
- **Expand:** reaction panels, repeated visual motifs, entrances, transformations.
- **Compensate:** turn narration into composition, symbols, or dialogue economy.
- **Failure:** prose captions carrying work the drawings should perform.

## Animation

- **Native carrier:** motion, timing, voice performance, music, transformation.
- **Recurring unit:** cut, sequence, episode, cour.
- **Preserve:** motion grammar, voice registers, signature sound/image motifs.
- **Compress:** side plots that cannot earn screen time.
- **Expand:** action choreography, silence duration, recurring audio cues.
- **Compensate:** convert prose interiority into acting, framing, sound, or visual metaphor.
- **Failure:** treating animation as colored panels or filling every silence with dialogue.

## Games

- **Native carrier:** player verbs, rules, feedback, replayability.
- **Recurring unit:** action loop, encounter, quest, run, route.
- **Preserve:** audience fantasy as something the player repeatedly does.
- **Compress:** noninteractive exposition.
- **Expand:** choice residue, resource pressure, build/cast differentiation.
- **Compensate:** turn character claims into mechanics, barks, availability, and consequences.
- **Failure:** a story pasted over unrelated gameplay.

### Visual Novel / Otome

- **Native carrier:** route contrast, choice framing, cumulative intimacy.
- **Recurring unit:** choice, scene, route gate, ending.
- **Preserve:** route-specific appeal and shared mystery.
- **Failure:** routes differing only in confession scenes.

### Gacha / Collectible Cast

- **Native carrier:** expandable roster, faction identity, collectible visual hooks.
- **Recurring unit:** unit acquisition, event chapter, upgrade, team composition.
- **Preserve:** one-line unit fantasy plus cast ecology.
- **Failure:** every unit receiving protagonist complexity or power escalation replacing identity.

## Live-Action Drama

- **Native carrier:** actor performance, blocking, social realism, episode momentum.
- **Recurring unit:** scene and episode.
- **Preserve:** relationship pressure, status behavior, practical stakes.
- **Compress:** effects-heavy spectacle without dramatic function.
- **Expand:** institutions, family/work ecology, subtext in ordinary spaces.
- **Compensate:** translate stylized traits into wardrobe, gesture, occupation, reputation, and recurring choices.
- **Failure:** sanding away the Headline Signature in the name of realism.

## Merchandise / Visual Products

- **Native carrier:** immediate recognition at reduced scale.
- **Recurring unit:** key art, icon, acrylic stand, figure, costume variant.
- **Preserve:** silhouette, palette, face/head anchor, prop, motif.
- **Compress:** narrative context.
- **Expand:** pose grammar, variant logic, paired/group composition.
- **Compensate:** turn invisible personality into posture and object relationships.
- **Failure:** alternate costumes erasing the character's visual invariant.
