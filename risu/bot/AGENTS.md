# Bot Authoring

- Bot creation, revision, or review: `authoring-bots`.
- A per-bot translation contract: `writing-translation-guides`.
- Exact CBS, lorebook, Lua, regex, trigger, HTML/CSS, or file syntax: the matching skill under `risu/common`.
- MCP artifact operations: `using-mcp-tools`.

Local bot project folders are ignored user work products. The tracked `skills/` and `docs/` directories hold guidance and the project's self-introduction templates.
